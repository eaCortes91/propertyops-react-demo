# PropertyOps React Demo

Polished React and TypeScript demo for a real estate operations team. The app models the kind of SaaS workflow a property operator would use every day: portfolio metrics, leasing applications, KYC review, maintenance queues, and revenue analytics.

Live demo: https://eacortes91.github.io/propertyops-react-demo/

## Why this exists

This repository is a public portfolio project built to show product engineering range in a recruiter-friendly format. It is inspired by real operational problems, but every property, applicant, ticket, and metric is fictional.

## Highlights

- React 19 + TypeScript + Vite
- Responsive operational dashboard with mobile navigation
- Light and dark UI modes
- Searchable property portfolio with real image assets
- Leasing pipeline with staged application cards
- Maintenance table with priority and SLA signals
- Recharts-based revenue and lead-source analytics
- Clean component structure and strongly typed mock domain data

## Tech stack

- React
- TypeScript
- Vite
- Recharts
- Lucide React
- CSS modules-style global layout using design tokens
